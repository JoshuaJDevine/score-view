# wizard — New Score wizard
`web/features/wizard.js` · loads after its data files `wizard-plugins.js`, `wizard-presets.js`, `wizard-templates.js`

## Purpose
Builds an ensemble's tracks in the open Bitwig project (names, groups, colours, articulation-map Note FX, instrument
plug-in or preset), optionally sets tempo, meter and section markers, then starts an empty score for it. "Swap
library…" swaps one track's instrument. **Brief** shows the starter sheet of the last New Score.

## Owns
- Toolbar: **New Score…** `#svwOpen`, **Brief** `#svwBriefBtn`; dialog ids `#svw*` (`#svwTpl`, `#svwRows`,
  `#svwPreview`, `#svwOptTempo`, `#svwOptMarkers`, …).
- `SV.wizard` (`open`, `close`, `openSwap`, `openPalette`, `runPlan`, `status`, `rows`, `openSheet`, …).
- localStorage `scoreview.wizard.*`.
- Data files: `wizard-templates.js` (pure: templates, palette, plan text, starter sheet; `window.SV_WIZARD_TEMPLATES`
  and `module.exports`), `wizard-plugins.js` (generated by `node tools/scan-plugins.mjs`), `wizard-presets.js`
  (generated by `tools/harvest-presets.mjs`). Re-run the generators rather than hand-editing.
- Relies on `NewScoreWizard.java`: `POST /api/wizard`, `POST /api/wizard?cancel`, `GET /api/wizard[?caps]`.

## Hooks
None; calls `SV.newScore(...)`, reads `SV.instruments`.

## Tests
