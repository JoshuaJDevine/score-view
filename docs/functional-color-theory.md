# Functional Color Theory (the user's system)

Source: the user's document "Functional Color Theory: A Psychological Approach to Harmonic Visualization"
(`FCT.pdf`, on the user's Desktop). This is a faithful summary for implementers; the user's terminology
and colour assignments are authoritative.

**Core idea.** Tonal music works through three psychological states created by harmonic function. Colour
makes the expectations — and their fulfilment or subversion — visible. *Rest. Motion. Tension. Everything
else is elaboration.*

## Primary functions
| Colour | State | Function | Examples | Teaching language |
|---|---|---|---|---|
| **Red** | Rest — stability, home, arrival | Tonic | I, i, any chord functioning as a temporary tonic | "We're home" |
| **Yellow** | Motion — stirring, departure, gentle energy | Subdominant | IV, iv, any departure from tonic without urgent resolution | "We're going somewhere" |
| **Blue** | Tension — urgency, pull toward resolution | Dominant | V, V7, vii°, any chord demanding resolution | "We can't stay here" |

## Secondary (mixed) functions
| Colour | Blend | Function | Examples | Notes |
|---|---|---|---|---|
| **Green** | Motion + Tension | Supertonic | ii, ii7, ii° | restless, seeking direction; "Wandering" in drifting progressions |
| **Purple** | Rest + Tension | Mediant | iii, iii7, ♭III | bittersweet, comfort with unease |
| **Orange** | Rest + Motion | Submediant | vi, ♭VI | warm departure; "Longing" as deceptive resolution or in modal contexts |

## Special categories
* **Borrowed tones — bright Cyan / Magenta.** Notes outside the current tonal system: secondary dominants
  (V/V, V/vi…), augmented sixths (It+6, Fr+6, Gr+6), modal interchange, chromatic passing tones with
  harmonic weight. **Key identifier: the raised fourth (♯4)** — the "smoking gun" of harmonic tension.
  These show harmonic "lies": expectations created but not fulfilled.
* **Non-chord tones — white/grey/neutral.** Passing, neighbour, suspension, anticipation: decorative, no
  functional colour.

## Expectation and subversion
* Every harmony sets up an expectation; fulfilment satisfies, subversion surprises.
* **Deceptive resolution**: expected Blue→Red (V→I), actual Blue→Orange (V→vi) — the shift should be obvious.
* **ii–V–I** = Green→Blue→Red. **Tritone substitution** ♭II7 gets the same Blue as V7.
* Endings: Blue ending = "eternal question", Yellow ending = "eternal journey".
* Modulation / chromatic wandering: borrowed colours show excursions; track the return journey;
  romantic pieces may visibly pass through many tonal centres.

## Intended uses (from the document)
Composition aid ("see the psychological weight of harmonic choices in real time"), score analysis,
emotional arc and harmonic rhythm for songwriting/film (tension build and release, leitmotif colouring),
teaching ("Red = happy home, Yellow = going somewhere, Blue = need to go home").
